# Historical Syria Explorer

Mobile-first experimental viewer for historical satellite imagery of Hama, Syria.

## Current version

- Pure image view with no Google labels or place names
- Mobile pinch zoom and drag
- Double-tap to reset
- Hama 1966 KH-7 scene

## Publish with GitHub Pages

Open the repository on GitHub, then go to:

`Settings → Pages → Build and deployment → Deploy from a branch`

Choose:

- Branch: `main`
- Folder: `/ (root)`

Save. The site will appear at:

`https://triavision-ai.github.io/historical-syria-explorer/`

## Source note

The current image is a remote preview. A future version should store an authorized local image asset or serve original USGS imagery through a backend for reliable full-resolution viewing.
